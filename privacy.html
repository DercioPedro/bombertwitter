Política de Privacidade

Última atualização: Fevereiro 2025

Coleta de Dados

Este aplicativo coleta apenas:

  • Token de autenticação do Twitter (para enviar mensagens)
  • Nome e nome de usuário do Twitter (para exibição)

Uso dos Dados

Os dados são usados exclusivamente para:

  • Enviar mensagens para grupos/comunidades
  • Autenticar sua conta do Twitter

Armazenamento

Não armazenamos seus dados em servidores. O token é salvo localmente no seu navegador.
